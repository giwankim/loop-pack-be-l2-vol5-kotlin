# Observability notes

Study notes on observability and monitoring with the Spring Boot stack.
Source book: *Cloud Native Spring in Action* (Thomas Vitale, Manning).

| File | Purpose |
| --- | --- |
| `00-map.md` | How the pieces fit together; redrawn as understanding changes |
| `book/` | One file per chapter, written while reading |
| `topics/` | One file per concept, created when it shows up in a second chapter |
| `lab-log.md` | Dated experiments: tried X, expected Y, got Z |
| `cheatsheet.md` | Queries, properties and patterns to look up again |

## Markers used in running notes

- plain bullet: an idea in my own words, with a page number
- `?` a question that came up
- `!` a surprise, or something that contradicts what I assumed
- `→` something to try in code

At the end of a chapter, collect the `?` and `→` lines into the wrap-up.
New chapter: copy `book/_chapter-template.md`.
